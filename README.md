# Requerimientos Funcionales - Simulador de Cajero Automático

## RF1 – Autenticación de Usuario
El sistema debe permitir al usuario autenticarse ingresando un número de cuenta y un PIN.

## RF2 – Visualización del Menú Principal
Una vez autenticado, el sistema debe mostrar un menú con las opciones disponibles: consultar saldo, retirar, depositar, convertir divisas y salir.

## RF3 – Consulta de Saldo
El sistema debe permitir al usuario consultar el saldo actual de su cuenta.

## RF4 – Retiro de Dinero
El sistema debe permitir al usuario retirar una cantidad específica del saldo disponible.

## RF5 – Depósito de Dinero
El sistema debe permitir al usuario depositar una cantidad específica en su cuenta.

## RF6 – Conversión de Divisas
El sistema debe permitir al usuario convertir una cantidad entre dos monedas disponibles usando una tasa de cambio predefinida.

## RF7 – Simulación del Dispensador de Efectivo
El sistema debe simular la entrega de efectivo cuando se realiza un retiro exitoso.

## RF8 – Manejo de Cuentas en Memoria
El sistema debe almacenar la información de cuentas de manera temporal (en estructuras de datos como listas o arreglos en memoria).
